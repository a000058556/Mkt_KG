# 來源收錄報告

收錄日期：2026-11-01。目標倉庫：a000058556/Mkt_KG（建立時為 private）。

## 官網

1. 由首頁新聞連結盤點得到 60 個文章 ID（1–60）。
2. 官網前端 NewsDetailPage 使用公開 `/api/news` 與 `/api/news/{id}`，並以 `lang=zh-TW/en/jp` 選擇語言。
3. 三種語言清單各回傳 60 筆；所有記錄的 content 欄位均非空。清單回應已包含正文 HTML，無須把首頁摘要冒充全文。以 ID 60 的 detail API 與清單回應交叉比對，正文一致。
4. API 原始回應按原始位元組保存；逐篇閱讀檔是 HTML 轉文字的衍生檔，格式不完全等同原頁。HTML 表格、連結、圖片位置仍可從 raw 回復。
5. 英文有 3 篇、日文有 4 篇正文與繁中完全相同：只標記相同，不推斷它們必然是有效翻譯或回退。語言欄位代表請求的語言，不是語言辨識保證。
6. 部分文章文字很少，主要資訊可能位於圖片；詳見 validation.json 的 low_text_records。本次只建立圖片 URL 清單，**未下載圖片、影片、附件，也未 OCR**。
7. 官網 insights 使用 `/api/articles?lang=zh-TW`，本次回傳空 data。
8. sitemap 與 API 的 ID 差異、語言筆數與驗證結果記錄於 `catalog/validation.json`。本次沒有探測未公開管理後台或私有內容。

## Facebook

網頁擷取工具無法取得貼文；一般 HTTP 回應未呈現可用貼文正文。使用公開瀏覽器開啟粉絲專頁，關閉登入提示後，可見最新一篇貼文，按「查看更多」取得全文。移到頁面下方後，歷史 feed 一直顯示「載入中」及「花費的時間比預期長」，因此僅收錄一篇，不假設歷史貼文不存在。

- 保留貼文 permalink、原文、圖片頁面網址；移除 Facebook 追蹤參數。
- 時間只顯示「3天前」，published_at 為 null。
- 原文「了解更多 DefenseTrust」連到 TrafficShaper，忠實保留，沒有擅自修正。
- 不收集訪客留言、按讚者、登入資訊或 cookie。
- 完整歷史需要粉絲專頁管理者提供可合法取得的貼文匯出（JSON／CSV／HTML），或具權限的官方 API 匯出；補入時仍應保留 post ID、永久連結、時間與內容。

- 加入使用者指定的 iThome 178631 後，共 15 個不重複外部網址；指定的 CIO 109792 已在清單內。
- 指定兩篇已讀取並整理短摘要。摘要清楚標示為生成內容，content_text=null，不假裝是 raw 全文。其他 13 筆為官網列出的參考資料，未逐篇聲稱取得外部正文。
- 第三方完整文章未複製入庫；後續可補公司持有權利或已獲授權的新聞稿原檔。僅公開可讀並不等於取得全文重製授權。
- 官網媒體清單的 newsDate 是官網所列日期，不一定等於原媒體發布日。兩篇指定來源另外記錄原媒體日期。

## 驗證
