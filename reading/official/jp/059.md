PHP の重大な脆弱性に関するお知らせ
PHP セキュリティチームは、相互に関連する重大な脆弱性 CVE-2026-109618 および CVE-2026-109619 を公表しました。CVSS v4.0 スコアはいずれも 9.2 です。
想定される影響
特定の条件下で、認証されていない攻撃者が細工した HTTP リクエストを送信し、Web ワーカープロセスの権限で任意のコードを実行する可能性があります。
悪用を試みる攻撃が観測されています。速やかに修正を適用し、ログをご確認ください。

外部からアクセス可能なサービスを優先してください。悪用条件は PHP の設定、拡張機能、アプリケーションの動作によって異なります。

各脆弱性の概要
CVE-2026-109618
			メモリ不足（OOM）により初期化が中断されると、終了処理が初期化未完了のデータを使用し、メモリ破損やリモートコード実行につながる可能性があります。
CVE-2026-109619
			グローバル状態に、解放済みのリクエスト用メモリへの参照が残ります。同じワーカーが後続のリクエストでこれを使用すると、解放後使用（use-after-free）が発生する可能性があります。
両脆弱性は特定の条件下で認証不要のリモートコード実行（RCE）につながります。実行権限は Web ワーカーに依存し、必ずしも root 権限を取得するわけではありません。
