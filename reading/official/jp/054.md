DefenseCloud クラウド型脅威インテリジェンス × DefenseTrust オンプレミス・リアルタイム防御
ランサムウェア、悪意のある Web サイト、フィッシング攻撃、C&C 通信などのサイバー脅威が増加する中、企業に求められるのは、単にファイアウォールを導入することではありません。 重要なのは、次のポイントです。
✓ 最新の脅威インテリジェンスをリアルタイムで把握できていますか？
✓ 悪意のある IP アドレスや DNS ドメインを迅速にブロックできますか？
✓ 攻撃が発生する前に脅威を防ぐことができますか？
DefenseCloud と DefenseTrust は、クラウドベースの脅威インテリジェンスとオンプレミスでのリアルタイム防御を組み合わせ、企業がプロアクティブで継続的に更新されるサイバーセキュリティ防御基盤を構築できるよう支援します。
グローバル脅威インテリジェンスをリアルタイムに更新
DefenseCloud は、SaaS 型の脅威インテリジェンスプラットフォームです。分散型ハニーポットネットワークを通じてグローバルな脅威インテリジェンスを継続的に収集・更新し、リアルタイム性・高効率・高いレジリエンスを備えたサイバーセキュリティ基盤の構築を支援します。
主な機能
1. グローバル脅威インテリジェンスのリアルタイム検索
世界中の最新の悪意ある IP、ドメイン、DNS に関する脅威インテリジェンスをリアルタイムで検索・参照できます。
2. DefenseTrust とのシームレスな連携
クラウドベースの脅威インテリジェンスとオンプレミスのリアルタイム防御をシームレスに連携し、既知の脅威がネットワークへ影響を及ぼす前に自動的にブロックします。
3. 脅威インテリジェンス・サブスクリプションサービス
継続的に更新される脅威インテリジェンスフィードを提供し、新たなサイバー脅威に対してセキュリティ環境を常に最新の状態に維持します。
4. 年間脅威インテリジェンスサービス
年間サブスクリプションにより、継続的に更新されるプレミアム脅威インテリジェンスと専門的なサポートをご利用いただけます。

DefenseCloud は、リアルタイムで収集される数百万件のサイバー攻撃データをインタラクティブなグローバル脅威マップとして可視化し、攻撃元、脅威ホットスポット、最新のサイバー攻撃動向をリアルタイムで把握できる環境を提供します。
224 の国と地域をカバーする脅威インテリジェンスを、グローバルなハニーポットネットワークを通じて継続的に更新することで、企業は高リスクの攻撃元を迅速に特定し、脅威がビジネスへ影響を及ぼす前に、プロアクティブなセキュリティ対策を実施できます。
直感的なダッシュボードとリアルタイム分析機能により、セキュリティ担当者はサイバー脅威の分布や規模を可視化し、トラフィック制御、不正通信の遮断、自動化された脅威対応など、より効果的なセキュリティ対策を実現できます。
オンプレミスで実現するリアルタイム脅威防御
DefenseTrust は、包括的な IP・ドメイン脅威インテリジェンスデータベースを提供し、フィッシングサイト、マルウェアのダウンロード、ボットネット、C&C（Command and Control）通信などの既知の脅威を自動的にブロックします。
インライン構成により、DefenseTrust はネットワーク遅延を最小限に抑えながら高速な脅威検査を実現し、最新の脅威インテリジェンスを継続的に同期します。完全自動化された脅威インテリジェンス更新により、運用管理の負荷を大幅に軽減し、新たなサイバー脅威への迅速かつ効率的な対応を支援します。
さらに、ハードウェアバイパス機能とソフトウェアバイパス機能を標準搭載しており、機器障害や電源障害が発生した場合でもネットワークの可用性を維持し、システム停止による業務への影響を最小限に抑えます.

ユーザーによる偽装 Web サイトへのアクセスを防ぎ、認証情報の窃取リスクを低減します。
