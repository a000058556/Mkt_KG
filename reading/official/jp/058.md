## 原文轉文字（原始 HTML 以 raw API 為準）

悪意のあるIP、ドメイン、その他のネットワーク脅威の発生源は、常に変化し続けています。企業にとっての課題は、単にセキュリティソリューションを導入することだけではありません。より重要なのは、防御の基盤となる脅威インテリジェンスが継続的に更新されているかどうかです。
セキュリティ対策が古い脅威データに依存している場合、新たに出現した悪意のあるIPやドメインによって、防御にギャップが生じる可能性があります。DefenseTrust は、IP／Domainの脅威インテリジェンスを継続的に更新し、分類・照合を行います。通信が既知の脅威インテリジェンスに一致した場合、企業があらかじめ設定したセキュリティポリシーに基づいて、その通信をブロックできます。

脅威インテリジェンスの照合から、ポリシーベースのブロッキングへ
DefenseTrust は、脅威インテリジェンスをネットワーク防御に直接活用し、企業がより迅速な IP／Domain 防御の仕組みを構築できるよう支援します。ネットワーク通信が発生すると、DefenseTrust は脅威インテリジェンスデータと照合します。
 
· IP 脅威インテリジェンス照合：接続先 IP が既知の脅威インテリジェンス分類に該当するかを識別します。
· Domain 脅威インテリジェンス照合：脅威インテリジェンスに基づいて Domain を分類・識別します。
· ポリシーベースのブロッキング： IP または Domain が脅威インテリジェンスに一致した場合、企業があらかじめ設定したセキュリティポリシーに基づいてブロックします。
· 継続的に更新される脅威インテリジェンス：脅威データを継続的に更新し、古いブラックリストに依存することで生じる防御のギャップを低減します。
DefenseTrust は、単に「検索できる」脅威インテリジェンスを、企業ネットワークで実際に活用できる防御へとつなげます。
DefenseTrust 脅威インテリジェン

ブラックリストは多ければよいわけではありません ― 重要なのは、脅威インテリジェンスを最新の状態に保つことです 
従来の静的なブラックリストでも、既知の悪意ある送信元をブロックすることはできます。しかし、サイバー脅威は常に変化し続けています。新たな IP、Domain、攻撃インフラが次々と出現する中、脅威データが継続的に更新されなければ、既存の防御ルールは徐々に有効性を失う可能性があります。
DefenseTrust は脅威インテリジェンスを継続的に更新し、企業が既知の悪意ある IP や Domain を識別し、その情報をネットワークアクセス制御ポリシーに直接活用できるよう支援します。
脅威インテリジェンス更新 ⮕ IP / Domain の分類・照合 ⮕ 脅威インテリジェンス一致 ⮕ ポリシーベースのブロッキング
これにより、脅威インテリジェンスを企業ネットワーク防御の実践的な一部として活用できます。

ブロックするだけではなく、ログから脅威インテリジェンスの一致状況を把握
 IT／セキュリティ担当者にとって、重要なのは防御することだけではなく、実際に何が起きたのかを把握することです。DefenseTrust は、日常の運用やインシデント確認において、脅威インテリジェンスの一致状況をより明確に把握できるよう支援します。
ログ情報を通じて、DefenseTrust は管理者が以下を確認できるようにします。
- 脅威インテリジェンスの一致記録
- 関連する IP / Domain 情報
- 一部の接続状況
