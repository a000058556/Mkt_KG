Combining Technical and Market Strengths to Enhance Network Performance for Global Enterprises.
[Taipei News, October 12, 2024]UGUARD NETWORKS, a leading expert in cybersecurity and top provider of network services, has partnered with AAEON, a leading supplier of embedded systems and IoT solutions, to become global strategic partners. Together, they have tested two products from AAEON’s network equipment series, the FWS-7541 and FWS-7840. This collaboration aims to drive innovation and application in embedded network security technologies, offering global enterprises more efficient and secure network defense solutions. These solutions reduce manpower costs, increase operational efficiency, and strengthen corporate information security.

UGUARD and AAEON Partnership Highlights

As global digital transformation accelerates, enterprises face an increasing demand for high-performance network defense solutions. Leveraging its expertise in network security, UGUARD conducted functionality testing on AAEON’s FWS-7541 and FWS-7840, awarding them with UGUARD’s certification mark. Testing from the perspective of IT users, UGUARD affirmed the performance of AAEON’s products in real-world applications.

FWS-7541 and FWS-7840

1. FWS-7541:This is a 1U rack-mounted network appliance designed for integrating edge computing and network security applications, making it ideal for small and medium-sized businesses as well as enterprises with multi-site network architecture needs. Equipped with an Intel® Xeon® D-1700 processor, it provides workload-optimized performance in a more energy-efficient manner. The device’s I/O offers extensive functionality, making the FWS-7541 a low-power, high-performance solution for optimized network management. According to UGUARD’s testing results, the device maintains the capability to match large threat intelligence lists under high-load conditions, ensuring robust network protection.

2. FWS-7840: Designed for enterprise applications requiring greater flexibility and high-performance processing, the device is powered by the Intel® Xeon® W processor (codenamed Comet Lake), offering powerful data processing capabilities. With a higher core count and innovative technologies like Intel® Deep Learning Boost, it can quickly address complex network threats and data transmission demands. This device powers network applications such as threat defense, the latest global threat intelligence, next-generation firewall management (NGWM), unified threat management (UTM), and even AI edge servers. UGUARD’s expert security testing ensures the device provides real-time response and high-efficiency network protection, meeting enterprise-level security requirements.

  
Product Testing Results

  
Leveraging its expertise in network security, UGUARD conducted functionality and security tests on the FWS-7541 and FWS-7840:

  
·Network Performance Testing： The test evaluated the device’s data processing capabilities under high-load conditions to ensure it can provide stable connections and data transmission in complex network environments.
·Security Protection Testing：Simulating various large-scale network attacks, the test assessed the device’s security defense capabilities to ensure it can respond in real-time to network threats.

UGUARD and AAEON’s Vision：Technical collaboration and exchange to jointly promote global network security development.

UGUARD CEO Jason Yen commented: “As global cybersecurity challenges intensify, UGUARD NETWORKS and AAEON have united to offer real-time, secure global threat intelligence and robust network solutions. This collaboration enhances cybersecurity defences, bolsters data privacy, and strengthens the resilience of global networks.”

“This certification illustrates our commitment to providing world-class network platforms that meet the needs of diverse enterprises,” said Howard Lin, CEO of AAEON. “UGUARD has a very forward-thinking philosophy that considers the complex and evolving nature of network security, which is consistent with AAEON’s flexible approach to the needs of its customers.”
