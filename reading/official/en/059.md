Critical PHP Security Advisory
Dear Customers,
The PHP Security Team has disclosed two related critical vulnerabilities, CVE-2026-109618 and CVE-2026-109619. Both have a CVSS v4.0 score of 9.2.
Security Impact
Under specific conditions, unauthenticated attackers may send crafted HTTP requests to execute arbitrary code with web worker privileges.
Exploitation attempts have been observed. Patch promptly and review logs.

Two Related Flaws Enable Remote Compromise
Prioritize internet-facing services. Exploitability varies with PHP configuration, extensions and application behavior.

Vulnerability Details
CVE-2026-109618
			An out-of-memory (OOM) error can interrupt initialization. Cleanup may then use incompletely initialized data, causing memory corruption and remote code execution.
CVE-2026-109619
			Global state can retain pointers to freed request memory. A later request handled by the same worker may reuse that stale state, causing a use-after-free.
Both flaws may allow unauthenticated RCE under specific conditions. Execution uses web worker privileges and does not necessarily grant root access.

Immediate Update Recommended
Install a release below or a later patched release in the same branch, or apply a complete vendor-validated backport. Configuration changes do not replace patching.
