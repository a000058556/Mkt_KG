PHP 重大漏洞公告
致親愛的客戶：PHP 安全團隊發布兩項互相關聯的重大漏洞 CVE-2026-109618 與 CVE-2026-109619，CVSS v4.0 評分皆為 9.2。
風險說明
在符合漏洞觸發條件的未修補環境中，未經身分驗證的攻擊者可能透過特製 HTTP 請求，以 Web／PHP 工作程序的權限執行任意程式碼。
已有攻擊嘗試被觀測到，請儘速修補並檢視日誌。

兩項漏洞互相關聯，網站可能被遠端接管
優先處理可由外網存取的服務。實際利用條件會隨 PHP 設定、擴充套件及應用程式而異。

兩項漏洞的差異
CVE-2026-109618
			記憶體不足（OOM）中斷初始化後，清理程序可能使用尚未有效初始化的內部資料，導致記憶體損毀與遠端程式碼執行。
CVE-2026-109619
			全域狀態仍指向已釋放的請求記憶體。同一 worker 處理後續請求時，可能誤用殘留狀態，造成 use-after-free。
兩項漏洞均可能導致未驗證 RCE，但須符合觸發條件。取得權限取決於 Web 工作程序，並不必然是 root。
