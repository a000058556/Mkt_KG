惡意 IP、Domain 與網路威脅來源持續變化，企業面對的挑戰，不只是部署資安設備，更重要的是：公司防禦的威脅情資，是否持續更新？
如果資安防禦依賴長時間未更新的威脅資料，當新的惡意 IP / Domain 出現時，將產生防護落差，DefenseTrust 透過持續更新的 IP / Domain 威脅情資，進行分類與比對，當連線命中威脅情資時，即可依企業所設定的安全策略進行阻擋。

從威脅情資比對，到策略阻擋
DefenseTrust 將威脅情資運用在實際網路防護中，協助企業建立更即時的 IP / Domain 防禦機制，當網路連線發生時，DefenseTrust 可依據威脅情資進行比對：
• IP 威脅情資比對：辨識連線 IP 是否符合已知威脅情資分類。
• Domain 威脅情資比對：針對 Domain 進行威脅情資分類與識別。
• 策略阻擋：當 IP / Domain 命中威脅情資時，可依企業所設定的安全策略進行阻擋。
• 持續更新威脅情資：持續取得更新的威脅資料，降低依賴未更新的黑名單所產生的防護落差，讓威脅情資不只是「查得到」，更能實際應用於企業網路防護。

黑名單不是愈多愈好，重要的是情資能否持續更新
傳統靜態 Blacklist 可以阻擋已知的惡意來源，但網路威脅不會停留在原地，新的 IP、Domain 與攻擊基礎設施持續出現，如果威脅資料無法持續更新，既有防禦規則也可能逐漸失去時效性。
DefenseTrust 透過持續更新的威脅情資，協助企業掌握已識別的惡意 IP / Domain，並將情資直接應用於網路存取策略，讓威脅情資真正成為企業資安防禦的一部分，從：威脅情資更新 ⮕ IP / Domain 分類與比對 ⮕ 威脅情資命中 ⮕ 依策略進行阻擋。

不只阻擋，也能從日誌掌握威脅情資命中狀況
對 IT／資安人員而言，不只防禦，也需要了解實際發生了什麼，DefenseTrust讓 IT 在進行日常維運與事件確認時，可以進一步了解威脅情資在實際網路環境中的命中情況。
DefenseTrust 透過日誌資訊，協助管理人員掌握：
• 威脅情資命中紀錄
• 相關 IP / Domain 資訊
• 部分連線狀況
• 策略處理結果
